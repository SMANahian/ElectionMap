# Result From Sources

Raw scraped election results and cross-source verification reports.

## Data Sources

### TBS News (The Business Standard)
Scraped by `scripts/scrape_votes.py` from the TBS election portal (`tbsnews.net/election-2026`). The portal embeds a JSON object (`election2026`) containing complete vote counts for all candidates across all 300 constituencies.

- `result_from_tbsnews.csv` — seat-level results (total votes, coalition votes/ratios)
- `tbsnews_party_totals.csv` — national vote totals per party
- `tbsnews_party_by_seat.csv` — per-party votes broken down by constituency

### The Daily Star
Scraped by `scripts/scrape_dailystar.py` from locally downloaded district pages (fetched by `scripts/download_dailystar.py` via the Daily Star API). Shows top 2 candidates with vote counts per seat, plus voter demographics (male/female/hijra).

- `result_from_dailystar.csv` — seat-level results
- `dailystar_party_totals.csv` — national vote totals per party
- `dailystar_party_by_seat.csv` — per-party votes broken down by constituency

## Verification Reports

Generated by `scripts/verify_sources.py` and `scripts/verify_alliances.py` to cross-check data consistency between the two sources:

- `verification_summary.csv` — overall match statistics (how many seats agree, disagree)
- `verification_seat_mismatches.csv` — seat-level discrepancies (total votes, coalition ratios, winner disagreements)
- `verification_vote_mismatches.csv` — candidate-level vote count differences (uses fuzzy name matching to align candidates across sources)
- `verification_party_total_mismatches.csv` — national party total differences
- `alliance_mismatch_report.csv` — BNP Alliance vs Eleven-Party Alliance vote discrepancies between sources, sorted by magnitude

## Regenerate

```bash
# Scrape TBS
python scripts/scrape_votes.py --config config/coalitions.json \
  --url https://www.tbsnews.net/election-2026 \
  --local_html data/tbs_election_2026.html --save_html

# Download & scrape Daily Star
python scripts/download_dailystar.py
python scripts/scrape_dailystar.py

# Verify
python scripts/verify_sources.py
python scripts/verify_alliances.py
```
