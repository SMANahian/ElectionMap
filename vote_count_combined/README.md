# Combined Vote Counts

Merged election results combining data from two independent sources: **TBS News** and **The Daily Star**.

## How it's computed

1. **Scraping**: Two independent scrapers collect constituency-level vote data:
   - `scripts/scrape_votes.py` extracts the embedded JSON from TBS News election portal
   - `scripts/scrape_dailystar.py` parses downloaded Daily Star district pages

2. **Normalization**: Seat names are normalized across sources using `scripts/normalize.py` (handles hyphens, spacing, "Parbatya" prefixes, etc.)

3. **Merging**: `scripts/combine_votes.py` matches seats between sources and for each party takes the **maximum** vote count when sources disagree, since underreporting is more common than overreporting

4. **Coalition calculation**: Party votes are grouped into alliances using definitions from `config/coalitions.json`, and coalition ratios (vote share) are recalculated from the merged totals

5. **Discrepancy tracking**: Any differences between sources are flagged in a `comments` column

## Files

### combined_vote_counts.csv
Master merged dataset with one row per constituency (300 seats). Contains:
- Seat name and normalized identifier
- Total votes cast
- Per-party vote counts (merged from both sources)
- Coalition-level vote totals and ratios (BNP Alliance, Eleven-Party Alliance, etc.)
- Discrepancy flags

### top_alliances_overview.csv
Focused comparison dataset for **BNP Alliance** vs **Eleven-Party Alliance**. Generated by `scripts/run_combine_top_alliances.py` with the same merge logic but filtered to the two major alliance blocs.

## Regenerate

```bash
# First scrape both sources
python scripts/scrape_votes.py --config config/coalitions.json ...
python scripts/scrape_dailystar.py ...

# Then combine
python scripts/combine_votes.py
python scripts/run_combine_top_alliances.py
```
